meta-styles Milestone 13 · Mock DM chat

Demo harness only — a synthetic, offline Instagram-DM thread backed by the local mock bot. Nothing here touches real Instagram. The chat starts empty: there is no seed data; share a photo below to put the first bubble in the thread.

Mock: unknown.

How to run the demo

  1. Start the mock bot (separate server process): node mock-ig-bot/server.js — listens on http://127.0.0.1:8904 by default.
  2. Serve this folder: python3 -m http.server 8000 from app/, then open http://localhost:8000/mock-dm.html.
  3. Paste the demo token SYNTH_mock_token when asked (non-secret demo value; the real bot token never goes here).

How to share a photo

Pick an image file below (or drag-drop it onto the chat box) and hit Share. The photo is injected into the mock as an inbound share (POST /mock/incoming-photo) and appears as an incoming bubble. Then open index.html — its inbox, pointed at the mock, lists the new share; “Use this photo” loads it into the viewer.

How to trigger a send-as-app

Type the reply text (and optionally stage a share-card image), then hit “Send as app”. The page issues a byte-identical POST /ig/send with "confirm": true; the text appears as an outgoing bubble, fed by the mock’s own send handler.

How to point index.html at the mock

No step needed: app/inbox-bridge.js ships with BOT_BASE pointed at the mock (http://127.0.0.1:8904). To use the real bot on Autumn’s own machine instead, edit that one line to http://127.0.0.1:8903 (documented in a comment there).
